負面新聞整合網站－交付版
==========================

一、準備
1. 使用 Windows 10 或 Windows 11。
2. 安裝 64 位元 Python 3.11 或 3.12：
   https://www.python.org/downloads/
3. 安裝 Python 時務必勾選「Add Python to PATH」。
4. 第一次安裝套件及第一次使用 FinBERT 時，電腦必須能連上網路。

二、放入外部檔案
請把下列 Excel 放在本資料夾內：
1. Parameter_Event.xlsx（檔名以 Parameter_Event 開頭也可以）
2. Company_List.xlsx，或檔名包含「公司名單」或「成分股」的 Excel

三、啟動
1. 雙擊「一鍵安裝並啟動.bat」。
2. 第一次執行會安裝套件，可能需要數分鐘。
3. 等畫面顯示「網站已啟動」後，瀏覽器會自動開啟。
4. 使用期間不可關閉黑色命令視窗。

四、網站網址
http://127.0.0.1:8504/

五、若無法啟動
1. 查看同資料夾內的「啟動錯誤.log」。
2. 確認公司防火牆／Proxy 允許 python.exe 連線。
3. 確認 8504 連接埠沒有被其他程式使用。
4. 若方法二或完整整合在 FinBERT 階段失敗，通常是模型首次下載遭 Proxy 阻擋，
   需要請資訊人員允許連線至 huggingface.co。
